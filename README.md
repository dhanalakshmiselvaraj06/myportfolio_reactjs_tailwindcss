# Dhana Lakshmi Selvaraj — React Portfolio

A React + Vite + Tailwind CSS v4 portfolio starter with responsive navigation, dark/light mode, expandable experience entries, project filters, project detail dialogs, education, certifications, awards, and contact links.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Before deployment

- Put your latest PDF at `public//Dhana_Lakshmi_Selvaraj_SoftwareDeveloper_reactjs.pdf` or change the CV links in `src/App.jsx` and `src/components/Header.jsx`.
- Verify all job titles, dates, technologies, award metrics, and certification details.
- Add GitHub repository links to the project data in `src/components/Projects.jsx` when available.
- Confirm project dates and all demo URLs.
- Deploy to Vercel by importing the repository; Vite's default build command is `npm run build` and output directory is `dist`.

This starter uses generic visual symbols rather than requiring image assets. You can add screenshots in the project cards later.
